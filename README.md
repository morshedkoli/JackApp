# 📓 JackApp (Dokan Hisab) — Retail Store Daily Ledger & Credit Book (বাকির খাতা)

[![Next.js](https://img.shields.io/badge/Platform-Web_Application-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/Language-TypeScript_|_JavaScript-blue?style=for-the-badge)](https://www.typescriptlang.org/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

A digital ledger and credit book application (দোকান হিসাব / বাকির খাতা) designed for retail grocery shopkeepers and small merchant storeowners to record customer credit purchases and supplier payments.

---

## 🌟 Key Features

- **Customer Credit Book (বাকির খাতা)**: Record credit transactions, customer phone numbers, and payment promises.
- **SMS Payment Reminders**: One-tap customer reminder messages for pending credit balances.
- **Daily Sales & Cash Drawer**: Calculate daily cash sales, credit sales, and total profit margins.

---

## 🛠️ Technology Stack

- **Framework**: Next.js, React, Lucide Icons
- **Styling**: Tailwind CSS

---

## 🚀 Getting Started

```bash
# 1. Clone repository
git clone https://github.com/morshedkoli/jackappdokanhisab.git

# 2. Install dependencies
npm install

# 3. Launch application
npm run dev
```
